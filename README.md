# 🇲🇽 MapBiomas Mexico – Official GitHub Repository

## 🌎 Welcome to MapBiomas Mexico GitHub 🇲🇽

Welcome to the official GitHub organization of MapBiomas Mexico 🇲🇽.

Mapbiomas Mexico is a collective project that monitors land use land cover change across the complete Mexican territory. The method is based on Landsat 4-9 surface reflectance imagery to obtain annual maps and is implemented in Google Earth Engine.

This page provides access to all scripts used in the generation of thematic collections 🗂️, cross-cutting themes 🔎 and mosaics 🛰️
